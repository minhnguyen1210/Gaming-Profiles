# LLM usage log

Every significant use of an LLM tool in this project is recorded here, one row per use (spec section 6):
the tool, what we asked, and how we used or changed the answer.

## Policy (see [`CONTRIBUTING.md`](CONTRIBUTING.md), section 1)

- An LLM is a tutor and a checker, not the author. We use it to understand concepts, error messages and libraries,
  to get suggestions, and to review or debug our own code.
- Analysis, answers, conclusions and reflections are our own. Nothing in this log is a finding that came from an LLM.
- The LLM never runs `git commit`, `git push`, `git merge` or opens a Pull Request. Members type every Git command.
- We do not commit anything we cannot explain. Every line that an LLM suggested was read, run and understood by the
  member named in the row before it was kept.

## How to read the last column

Each row ends with what the member did with the answer, in three parts:

- **Checked**: how the member verified it (re-ran it, compared with the raw data, read the documentation).
- **Changed**: what the member edited, rewrote or fixed after the suggestion.
- **Rejected**: what the member did not use, and why.

`TODO` means the member has not filled the row in yet.
